# Invariant Analytics Kernel

A semantic validation layer for statistical data platforms.

## The Problem

- Users sum percentages and get wrong answers
- Users compare datasets with incompatible boundaries
- Users join data with different universe definitions

These errors are silent. The dashboard renders. The numbers look plausible. Decisions get made.

## What It Is Not

- Not a database
- Not a query engine
- Not a visualization layer
