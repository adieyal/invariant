# Reference

Lookup documentation for APIs, terminology, and interfaces.

## How to use this section

This section is for **lookup**, not learning. If you're new to Invariant, start with [Getting Started](../getting-started/index.md) or [Examples](../examples/index.md).

## Stability guarantees

| Stability | Meaning |
|-----------|---------|
| **Stable** | Breaking changes require major version bump |
| **Beta** | May change in minor versions |
| **Internal** | No stability guarantees |

All public APIs documented here are **Stable** unless marked otherwise.
