# Invariant Analytics Kernel

A semantic validation layer for statistical data platforms. Catches the mistakes that cause bad analysis—before they reach your users.

Invariant enforces semantic rules on statistical queries: it blocks naive indicator aggregation, checks dataset comparability, manages versioned reference systems with crosswalks, and produces disclosures that explain why operations succeed or fail.
